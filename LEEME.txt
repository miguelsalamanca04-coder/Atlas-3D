Qué es esto
-----------
El Atlas 3D con su primera estrategia de caché con nombre (Sesión 31,
espejo de la Sesión 20): el manejador de fetch ahora implementa Cache
First de verdad sobre los íconos y el shell — consulta el caché
primero, y si no encuentra el recurso, lo pide a la red y lo guarda con
cache.put() para la próxima vez. Enrutar distintas estrategias según el
tipo de recurso (con Network First y Stale-While-Revalidate ya sumadas)
es el trabajo de la Sesión 32. Importante: esto no significa que el
proyecto funcione sin conexión de verdad todavía — esa limitación,
explicada en la Sesión 29, sigue abierta hasta Workbox en la Sesión 34.
Es el punto de partida de hoy: no lo reemplaces, cotéjalo contra tu
propio proyecto si te quedaste atrás.

Cómo abrirlo
------------
  npm install
  npm run dev

Abre la URL que Vite imprime en la terminal (normalmente
http://localhost:5173).
