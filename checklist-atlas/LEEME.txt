Lista de verificación final del Atlas 3D — Sesión 45
Electiva - PWA · UPTC (Sub-bloque B)

Qué es
------
Un script de Node que abre la versión COMPILADA del Atlas en un Chromium real y comprueba 13 puntos:
  1      documento: idioma, viewport, descripción, un <main>, contexto seguro
  2, 3   manifest sin errores y sin errores de instalabilidad (se lo pregunta a Chrome)
  4, 5   Service Worker activo, precaché completo y la app abre con el servidor caído
  6      desplazamiento de diseño acumulado (CLS) menor que 0,1
  7-12   dibujo bajo demanda: la escena quieta no dibuja; girar, elegir pieza, cambiar de modelo y redimensionar sí
  13     una nota escrita no se pierde al marcar un favorito en otra tarjeta
Solo mira lo que se ve desde fuera (ids, clases, Chrome, red): sirve igual para la versión sin framework,
la de React y la de Angular.

Cómo usarla
-----------
  1. Requiere Node 18 o superior.
  2. En esta carpeta:   npm install
                        npx playwright install chromium       (baja el navegador de pruebas, ~150 MB)
  3. Compila tu proyecto (npm run build): debe existir su carpeta dist/.
  4. Ejecuta, indicando la carpeta del proyecto:
       Linux / macOS:   ATLASDIR=../mi-proyecto node checklist-atlas.js
       Windows (PowerShell):   $env:ATLASDIR="..\mi-proyecto"; node checklist-atlas.js
  5. La última línea dice «RESULTADO: todo en orden» o cuántos fallos hay. Cada «✗ FALLÓ» nombra el punto.
     El código de salida es 0 solo si todo está en orden.

Notas
-----
  • El puerto de prueba es el 4350 (un servidor mínimo propio); si está ocupado, cámbialo en la línea «const PORT».
  • La prueba usa el renderizado por software (SwiftShader), de modo que funciona sin tarjeta gráfica.
  • El punto 13 falla a propósito en la versión de la Sesión 42: es el defecto que React y Angular evitan.
